3.1 GPS ARCHITECTURE
================================================================================

Space Segment
- Satellite constellation transmits one-way radio signals containing satellite position and time information
- Minimum 24 operating satellites
- Altitude: 20,000 km
- At least 4 satellites visible from any point on Earth at any given time
- Ensures global coverage and positioning capability

Control Segment
- Global network of monitoring and ground control stations worldwide
- Maintains proper satellite orbits through command maneuvers
- Adjusts satellite clocks
- Performs satellite tracking
- Monitors satellite health and status information
- Includes Monitor Stations, Master Control Stations, and Ground Antennas

User Segment
- GPS receiver equipment used by civilian and military users
- Collects transmitted satellite position and time information from visible satellites
- Processes signals to calculate three-dimensional position and time
- Provides navigation solutions

References:
- http://www.gps.gov

3.2 GNSS ERROR SOURCES
================================================================================

Clock-Related Errors
- Satellite clock stability: ~2.6–5.2 m error/day (1–2 × 10⁻¹³ stability)
- Relativistic effects: ~5 m residual error (after onboard compensation for 38.4 μs/day drift)
- Receiver clock drift: much larger than satellite clock error; requires estimation as 4th unknown (minimum 4 satellites needed)

Signal Propagation Errors — Sagnac Effect
- Relativistic error from Earth's rotation during signal propagation
- Error magnitude: ~30 m if uncompensated

Signal Propagation Errors — Ionosphere Delay
- Signal penetrates at ~1,000 km altitude through ionized gases
- Dispersive medium — delay is frequency dependent
- Error magnitude: up to 100 m in severe conditions
- Dual-frequency receivers eliminate ~99.9% of ionospheric delay
- Single-frequency receivers correct only ~50% using broadcast models
- Theoretical models correct up to 80% of ionospheric error

Signal Propagation Errors — Troposphere Delay
- Signal travels through lowest atmosphere layer (up to 20 km above sea level)
- Wet component (~10% of delay) difficult to model; dry component easier
- Frequency independent — cannot be removed through dual-frequency (L1/L2) combinations
- Error magnitude: 2.5–25 m depending on satellite elevation angle

Signal Propagation Errors — Multipath Errors
- Signal reaches antenna via multiple paths (direct line of sight + reflections from surrounding objects)
- Delayed echoes are superimposed on direct signal
- Depends on surrounding environment
- Major error source
- Error magnitude: up to 100 m in bad/severe environments

System Errors
- Satellite orbit: satellite broadcasts updated data every 2 hours; curve fit of path introduces error of ~2 m
- Receiver noise: contributes to overall error budget (magnitude not specified in source material)

Intentional Errors
- Jamming: deliberate broadcasting of RF signals in the same frequency at higher power near the receiver, aiming to prevent tracking of GNSS signals
- Spoofing: fake signal designed to make the receiver believe it is a real GPS signal, tricking the system

References:
- Karaim, M., Elsheikh, M., & Noureldin, A. (2018). GNSS Error Sources. Multifunctional Operation and Application of GPS, 70–81.

3.3 DILUTION OF PRECISION (DOP)
================================================================================

DOP Metrics
- GDOP (Geometric DOP): general term describing the geometry of satellites; describes overall accuracy factor
- PDOP (Position DOP): geometry factor affecting three-dimensional position accuracy
- HDOP (Horizontal DOP): geometry factor affecting horizontal position accuracy only
- VDOP (Vertical DOP): geometry factor affecting vertical position accuracy only

Key Points
- DOP depends on the geometry of visible satellites; the better the geometry, the lower the DOP, and hence the better the position solution
- DOP is used to select which satellites should be included in position calculations; an ideal receiver would select only the set of satellites with the minimum DOP

References:
- Karaim, M., Elsheikh, M., & Noureldin, A. (2018). GNSS Error Sources. Multifunctional Operation and Application of GPS, 70–81.

3.4 REAL TIME KINEMATICS (RTK) AND INTEGER AMBIGUITY
================================================================================

RTK — Principles
- Differential GNSS technique based on carrier phase measurements (not pseudo-code)
- Reference (base) station with well-known location transmits corrections to rover in real-time
- Main GNSS errors cancel out through differential processing: satellite clock bias, orbital error, ionospheric delay, tropospheric delay
- Rover determines position relative to base station, then adds base station position to calculate absolute position in global coordinate frame
- Service range: 10–20 kilometres
- Real-time communication channel required between base and rover
- Accuracy achieved: a few centimetres
- Commonly used in surveying applications

Integer Ambiguity
- Carrier phase ambiguity: an unknown integer number of times the carrier wavelength
- Needs to be fixed (resolved) to rebuild full range measurements from carrier phase measurements
- Carrier phase measurements have much smaller noise (~5 mm) compared to pseudo-code measurements (~1 m)
- Must be resolved to integer values to achieve centimetre-level accuracy (float solution only gives decimetre-level accuracy)
- Double differencing between two receivers eliminates non-integer terms, allowing ambiguities to be expressed as integers

- ESA Navipedia — Real Time Kinematics: https://gssc.esa.int/navipedia/index.php/Real_Time_Kinematics
- ESA Navipedia — RTK Fundamentals: https://gssc.esa.int/navipedia/index.php?title=RTK_Fundamentals

3.5 GNSS ACCURACY — POSITIONING TYPES AND EXPECTED ACCURACY
================================================================================

1. Standard Positioning Service (SPS)
- Free civilian GPS service based on broadcast signal only
- No reference station or corrections used
- Expected accuracy: ~1–10 meters typical
- Government commitment: daily global average URE ≤2.0 m with 95% probability (actual performance typically better)
- User Equivalent Range Error (URE): ≤0.643 m achieved on average (as of 2021)
- Commonly used for consumer-grade positioning and navigation

2. Differential GPS (DGPS)
- Uses reference station with known location to broadcast corrections to rover
- Code-based differential positioning: uses ONLY pseudo-code (pseudorange) measurements
- Pseudo-code measures signal travel time/distance (not carrier phase wavelengths)
- No integer ambiguity problem (code measurements are unambiguous)
- Expected accuracy: 1–3 meters (sub-meter level)
- Improvement over standard GPS: ~10-fold improvement (~1 m vs ~10 m for standard SPS)
- Practical range: works over larger distances (100+ km), accuracy degrades ~1 cm/km
- Commonly used for maritime navigation and surveying

3. RTK Float
- Uses carrier phase measurements (wavelength cycles) — not pseudo-code
- Intermediate state: carrier phase ambiguities estimated as floating-point numbers (not resolved to integers)
- Has integer ambiguity problem: exact number of complete wavelengths not yet determined
- Expected accuracy: 1–3 meters (sub-meter, but not centimeter-level)
- Transitional phase; may converge to fixed solution with better satellite geometry or signal conditions
- Not suitable for applications requiring centimeter-level precision

4. RTK Fixed
- Uses carrier phase measurements — much more precise than pseudo-code
- Final state: all carrier phase ambiguities successfully resolved to integer values
- Expected accuracy: 1–2 cm horizontal, 2–3 cm vertical
- Service range: 10–20 km from reference station (limited by ionospheric de-correlation)
- Target state for professional surveying and precision applications
- Convergence from float to fixed: typically seconds to minutes

Accuracy Comparison
- SPS: pseudo-code only, ~1–10 m, no corrections
- DGPS: pseudo-code only, ~1–3 m, no ambiguity
- RTK Float: carrier phase, ~1–3 m, ambiguities unresolved
- RTK Fixed: carrier phase, ~1–2 cm horizontal / 2–3 cm vertical, ambiguities resolved
